## Pour les Product Owners

- **[Modifier le contenu du site (guide pas à pas)](modifications-contenu.md)** —
  installer et configurer son ordinateur de zéro — **macOS ou Windows** — (git,
  GPG, GitHub Desktop, Docker, agent-vm, MCP Linear), puis faire de petites
  modifications de contenu (fiches métier, FAQ, wording, corrections de texte…)
  et ouvrir une pull request, sans connaissances techniques préalables.
